# Penalty Legends 3D

A standalone 3D penalty-shootout game built as a Progressive Web App (PWA). The game is bilingual (Arabic/English), has a moving goalkeeper, guided aiming, shot power, local best-score saving, and keyboard/touch support.

## Run locally

```bash
npm install
npm run dev
```

## Create a production build

```bash
npm run build
```

The output is created in `dist/`. Publish the `dist` folder to an HTTPS host, then use PWABuilder or Microsoft Partner Center to package the PWA for Microsoft Store. The project uses only original code and generated visual elements; it contains no real clubs, logos, players, or licensed game assets.
